# 🌿 Cek Barkot Tembakau Operations & Development Skill

Skill ini memuat arsitektur, domain data tembakau, protokol Supabase Realtime, standarisasi antarmuka HP lapangan, dan penanganan file Excel pada aplikasi **Cek Barkot**.

---

## 1. 📊 Domain & Struktur Data Tembakau

Aplikasi ini mencatat bal tembakau harian yang masuk gudang dan melacak status penempelan stiker barcode fisik.

### Entitas Utama
- **`tanggal`** (`DATE` / format `YYYY-MM-DD`): Tanggal pengolahan / penerimaan bal tembakau.
- **`no_gud`** (`INTEGER`): Nomor urut bal di gudang (No Gudang, misal: `107`, `324`).
- **`grade`** (`TEXT`): Kode kualitas/grade tembakau (misal: `50`, `52`, `55`, `60`, `63`, `65`, dll).
- **`barkot`** (`TEXT`): Nomor seri barcode stiker fisik yang ditempel (misal: `30146`, `31295`).
- **`kg`** (`NUMERIC`): Berat timbangan bal tembakau dalam kilogram.
- **`is_done`** (`BOOLEAN`): Status penempelan barcode (`true` = sudah dibarkot / hijau, `false` = belum).
- **`done_at`** (`TIMESTAMP WITH TIME ZONE`): Catatan waktu saat nomor dicentang di lapangan.

## 2. ⚡ Arsitektur Supabase & Sinkronisasi Realtime

### Skema Database (`public.barkot_data`)
```sql
CREATE TABLE IF NOT EXISTS public.barkot_data (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tanggal DATE NOT NULL,
    no_gud INTEGER NOT NULL,
    grade TEXT,
    barkot TEXT,
    kg NUMERIC,
    is_done BOOLEAN DEFAULT FALSE,
    done_at TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()),
    CONSTRAINT unique_tanggal_nogud UNIQUE (tanggal, no_gud)
);
```

### Aturan Realtime & Integrasi
1. **Channel Subscription**:
   - Selalu dengarkan event `postgres_changes` untuk tabel `barkot_data` dengan filter per `tanggal`.
   - Update UI secara *optimistic* saat tombol No Gud diklik, lalu sync ke Supabase (`upsert` / `update`).
2. **Offline & Fallback Mode**:
   - Jika koneksi Supabase gagal atau belum disetup, fallback otomatis menggunakan `SEED_DATA` / `localStorage`.
   - Simpan status centang lokal dan riwayat di browser agar tidak hilang saat jaringan lapangan terputus.

## 3. 📥 Format File Excel & Data Parser

### Struktur Kolom Excel Rekap (`.xlsx`)
File Excel buku sortir / rekap induk biasanya memuat:
- **No Gud / Nomor Bal**: Kolom angka urut bal.
- **Grade Tembakau**: Kolom klasifikasi grade.
- **Barkot / Barcode**: Nomor barkot yang dicetak.
- **Berat (Kg)**: Angka desimal/integer berat bal.

### Best Practices Parsing:
- Gunakan library SheetJS (`XLSX`) yang sudah diintegrasikan.
- Lakukan sanitasi header kolom (trim whitespace, lowercase normalization).
- Tangani format tanggal otomatis dari nama sheet atau sel judul.
- Berikan pesan error/toast yang jelas jika ada baris data yang korup atau tidak lengkap.

## 4. 📱 Standar UI Lapangan (Mobile-First / Rugged UX)

Aplikasi digunakan oleh mandor/petugas gudang di bawah kondisi lapangan (sinar matahari terang, penggunaan satu tangan di HP seperti **Samsung Galaxy A16** / iPhone).

### Prinsip Desain:
1. **Target Sentuh Besar**: Ukuran kartu No Gud minimal `48px - 64px` agar mudah ditekan tanpa salah pencet.
2. **Kontras & Warna Status Jelas**:
   - **Sudah Dibarkot**: Hijau tegas / aksen emerald (`#10b981` / background hijau cerah).
   - **Belum Dibarkot**: Netral / gelap kontras tinggi (`#334155` / border tegas).
   - **Spotlight / Missing**: Oranye / kuning menyala (`#f59e0b`).
3. **Preset Ukuran Teks**:
   - `16pm` (iPhone 16 Pro Max standard)
   - `a16` (Samsung A16 mode lapangan)
   - `lansia` (Teks ekstra besar & kontras tinggi)
4. **Feedback Multi-Sensori**:
   - **Audio Bip**: Web Audio API oscillator beep saat centang berhasil.
   - **Haptic Vibration**: `navigator.vibrate(50)` pada perangkat mobile yang mendukung.
   - **Lock Mode**: Mencegah salah klik (double tap confirmation atau kunci edit).

## 5. 📷 Scanner Barcode & Barcode Hilang / Belum Ditempel

- **Scanner Kamera**: Menggunakan `html5-qrcode` dengan kontrol kamera belakang (*environment*) dan toggle lampu senter (*torch*).
- **Missing Barcodes Tracker**: Daftar 9 barcode kritis yang belum ditempel (tersimpan di `localStorage` & banner dinamis) untuk memudahkan pencarian bal fisik yang tertunda.

## 7. 🛠️ Prosedur Upsert & Troubleshooting Mobile Sync (HP Lapangan)

### Troubleshooting Data Tidak Terupdate di HP:
1. **Verifikasi Jumlah Record Supabase Cloud vs Local Seed Data**:
   - Jika data tanggal tertentu (misal: tanggal 31) tidak muncul/tidak lengkap di HP, periksa jumlah record di Supabase Cloud (`barkot_data`).
   - Lakukan bulk upsert seluruh baris bal dari `seed_data.json` / `seed_data.js` ke Supabase REST API dengan query parameter `?on_conflict=tanggal,no_gud`.
2. **Cache Busting Asset JavaScript (`index.html`)**:
   - Browser mobile HP (Chrome Android & Safari iOS) melakukan caching agresif pada file `.js`.
   - Wajib menaikkan versi query string pada [`index.html`](file:///c:/Users/xenov/Downloads/cekbarkot/index.html) (contoh: `seed_data.js?v=3.3` & `app.js?v=3.3`) setiap kali ada penambahan data atau pembaruan logika aplikasi.
3. **Pemberihan Cache & Reload di HP Lapangan**:
   - Instruksikan petugas lapangan/mandor untuk menekan tombol **`🔄 Muat Ulang`** pada panel *Sinkronisasi Cloud & Berkas*.
   - Atau lakukan *hard refresh* / muat ulang halaman di browser HP untuk mengambil file JavaScript versi terbaru.
